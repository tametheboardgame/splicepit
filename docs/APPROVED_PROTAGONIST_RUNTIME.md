# Approved protagonist runtime

The first ultra-minimal 24×32 sprite implementation is rejected. The richer generated Milo, Theo, Ada and Pip directional sheets are approved as the visual basis for runtime assets.

Use 64×96 fixed runtime cells, one idle plus three walk frames in each of down/left/right/up. Render at 1× gameplay scale and 2× only for review. Preserve the detailed hair, layered clothing, boots, straps, grime and cyan biotech accents visible in the approved sheets.

Small later customisation may include skin tone and a limited number of authored accent/accessory variants. Do not use a whole-sprite tint because that would recolour clothing and equipment. Prefer targeted masks, palette variants or small overlays. A broad modular character creator remains deferred.
