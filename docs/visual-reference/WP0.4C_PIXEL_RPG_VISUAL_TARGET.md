# WP0.4C Pixel-RPG Visual Target

This reference is the approved visual aim for SplicePit following the WP0.4C reset.

## What this image establishes

- Classic top-down 2D RPG readability, structurally closer to late-era handheld monster RPGs than to an isometric action RPG.
- Original SplicePit art direction, not copied assets, maps, UI or characters from any existing game.
- Slightly more detailed and advanced rendering than the handheld reference point: richer materials, lighting accents, creature detail, animation potential and environmental clutter.
- Compact player/NPC sprites and tile-built environments with clear walkable routes.
- Workshop, underground market, overworld, creature-summary, splicing and battle views all belonging to the same visual language.
- Dark charcoal/metal base, controlled toxic green biotech light and dirty amber/orange industrial light.
- Battle creatures rendered larger than exploration sprites so grafts and splice outcomes remain visually legible.
- Menus and status UI presented as compact game interfaces rather than large web-style cards.

## Important interpretation rule

The image is a **visual target and composition reference**, not a literal production specification. Generated names, creature designs, exact layouts, text, UI placements and individual props are placeholders unless separately approved in the roadmap.

Future visual work packages should preserve the camera/readability/style principles shown here while producing original production assets and layouts that implement the actual SplicePit mechanics and world design.

## Explicitly not the target

- Painterly concept art used as gameplay graphics.
- Diablo-style/isometric or pseudo-3D exploration.
- Photorealistic or pre-rendered-looking gameplay.
- Giant HUDs or web-dashboard layouts.
- Huge rooms with tiny unreadable characters.
- Bright pastoral presentation.
