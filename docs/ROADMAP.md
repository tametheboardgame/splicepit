# SplicePit Development Roadmap

## R0 - Foundations
- Browser runtime and repository structure
- Tile movement and interaction
- Persistent local save state
- Data-driven animals/genes
- Splicing calculations, failure and mutation
- First Fit Pit combat loop
- Automated syntax and logic checks

## R0.1 - First playable vertical slice
- Opening aftermath card
- Small damaged pit environment
- Acquire a base animal
- Recover gene samples
- Freeform prototype splice bench
- Procedurally rendered splice appearance
- Demonstration Fit Pit bout
- Debt/reward feedback

## R0.2 - Vertical slice hardening
- Replace prototype interactions with authored map content
- Proper dialogue system and NPC state
- Compatibility/epistasis model for gene combinations
- Status effects, move sets and meaningful battle tactics
- Inventory and gene sample economy
- Better input handling for keyboard/controller/touch
- Accessibility and settings

## R1 - First real game chapter
- User-authored story content
- First exterior settlement/route
- Quest-driven gene acquisition
- Multiple base animals
- Creature management and naming
- Fit Pit ladder/opponents
- Production art and audio pipeline
