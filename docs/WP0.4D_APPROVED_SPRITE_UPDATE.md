# WP0.4D Approved Sprite Update

Human review rejected the first 24×32 ultra-minimal sprite pass and explicitly approved the richer protagonist sheets produced on 23 August 2026.

The approved runtime direction is therefore higher-detail authored pixel art, not bare 8-bit reduction.

Runtime export target:

- 64 × 96 px frame cells;
- 4 columns × 4 rows;
- rows: down, left, right, up;
- columns: idle, walk 1, walk 2, walk 3;
- gameplay scale: 1×;
- review scale: 2×;
- nearest-neighbour rendering;
- stable feet/origin across frames.

This decision supersedes earlier 24×32 references wherever they conflict.

Lightweight cosmetic customisation is permitted later, particularly skin tone and a small number of authored accessory/accent variants, provided Milo/Theo/Ada/Pip remain recognisable authored protagonists. Do not implement a broad modular character creator. Avoid crude whole-sprite tinting; use authored palette variants or targeted masks/overlays so skin changes do not recolour hair, clothes or biotech equipment.
